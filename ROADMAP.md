# AI Hotel — Validation Roadmap

## Stage 0 — Discovery

- map one real hotel;
- understand director workflow;
- map guest request flow;
- inventory current systems;
- identify data and integration constraints.

## Stage 1 — Workflow selection

Choose a small set of high-value workflows.

Hotel-side examples:
- Director Daily Brief;
- incident orchestration;
- verified delegation.

Guest-side examples:
- housekeeping/amenities;
- breakfast/restaurant;
- transport;
- late checkout;
- maintenance.

## Stage 2 — Demonstration

Use safe sample, synthetic or read-only data.

The demo should prove:
- context aggregation;
- structured intent/workflow;
- policy boundaries;
- human handoff;
- verification;
- visible status.

## Stage 3 — Concierge pilot

Run a bounded real pilot.

Progression:
1. read-only;
2. recommendations and drafts;
3. human-routed tasks;
4. selected approved low-risk actions;
5. measured outcome review.

## Stage 4 — Integration MVP

Only after validation:
- connect selected hotel systems;
- automate proven workflows;
- improve observability;
- add hotel configuration;
- formalize guest identity and permission handling.

## Stage 5 — Scale

Possible later directions:
- multi-property hotel groups;
- broader integration catalog;
- reusable hotel workflow library;
- portable guest preference layer;
- partner ecosystems.

Each stage remains evidence-gated.
